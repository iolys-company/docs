# iolys documentation

> iolys is an AI development workspace for Visual Studio on Windows. Connect coding-agent providers, hosted APIs, or Ollama models to work with your solution, review changes, and customize agent workflows.

The published documentation is at https://docs.getiolys.com/.
The links below point to the Markdown sources of these guides.
Available models, tools, authentication, and usage reporting depend on the provider and account. Screenshots illustrate the interface and are not current model or pricing inventories.
